## 한눈에 보기

2026년 EV 전환지원금은 **3년 내연차 폐차·매도 시 추가 100만 원**입니다. **국고 보조금 + 전환지원금 합산 시 중형 EV 최대 680만 원** 가능합니다. **수도권 지역은 5~6월 보조금 조기 소진 위험**이 크고, **6월 초 신청이 잔여 보조금 확보 + 6월 정보 공개 의무 시행 직후 매수 결정** 시점입니다. 캐스퍼 일렉트릭·EV6·코나 EV 같은 인기 모델은 본인 가용 보조금·전환지원금 적용 후 본인 부담을 계산해 결정합니다. 보조금 마감 + 정보 공개 + 신차 출고 일정을 종합 고려한 6월 신청이 안전한 시점입니다.

## 왜 이 질문이 생길까

2026년 EV 보조금이 전년 수준 유지 + 전환지원금 100만 원 신규 도입 + 중형 EV 최대 680만 원 보조금이 가능해지면서 EV 매수 검토가 늘고 있습니다. 본인이 출고 3년 이상 내연차 보유 + EV 전환 계획이 있다면 전환지원금 자격 충족 + 5~6월 보조금 잔여 확보 + 6월 정보 공개 의무 시행 같은 변수가 결정의 핵심입니다.

문제는 수도권 보조금 조기 소진입니다. 서울·경기·인천 등 수도권 지역은 EV 수요가 높아 보조금이 5~6월에 빠르게 소진되는 패턴이 있습니다. 2026 5월 시점에 일부 지자체 잔여 한도가 줄어들고 있고, 6월 중순~말 마감 가능성이 큽니다. 매수 결정이 늦으면 보조금 없이 자비 부담 매수 또는 다음 회차 보조금 대기 + 인도 일정 지연 위험이 있습니다.

또 한 가지는 6월 정보 공개 의무 시행과의 균형입니다. 6월부터 EV 배터리 제조사·용량·전압 정보가 의무 공개되어 본인 사용 환경에 맞춘 EV 선택 + 셀 효율 평가가 더 정확해집니다. 5월 매수는 정보 공개 직전이라 본인 선택의 투명성이 한정적이고, 6월 초 신청은 정보 공개 직후 + 보조금 잔여 확보의 균형 잡힌 시점이 됩니다.

이 글은 EV 전환지원금 100만 원 + 캐스퍼 EV·EV6·코나 EV 신청 시점 + 5~6월 잔여 보조금 + 수도권 조기 소진 위험 + 본인 부담 계산을 정리합니다.

## 단계별 체크리스트

1. **본인 내연차 보유 기간 + 전환지원금 자격 확인**: 출고 3년 이상 본인 명의 내연차 보유 + EV 전환 계획 시 전환지원금 자격이 됩니다. 본인 차량 등록증으로 출고 일자 확인 + 매도·폐차 절차 정리합니다. 자격 충족 시 100만 원 추가 보조금이 적용됩니다.
2. **본인 거주지 지자체 잔여 보조금 확인**: 수도권 지역은 5~6월 빠른 소진 패턴이라 본인 거주지 지자체 환경 부서 또는 EV 보조금 사이트에서 잔여 한도 확인이 필수입니다. 잔여 한도 적으면 5월 말 즉시 신청이 안전하고, 잔여 한도 많으면 6월 초 신청 가능합니다.
3. **6월 초 신청 + 6월 정보 공개 활용 균형**: 6월 초 신청은 보조금 잔여 확보 + 6월 정보 공개 의무 직후 본인에게 맞는 EV 선택 균형이 가장 좋은 시점입니다. 캐스퍼 EV·코나 EV·EV6 같은 옵션을 본인 사용 환경 + 셀·배터리 사양에 맞춰 선택합니다.
4. **본인 부담 + 5년 운영 비용 + 잔여가치 종합 평가**: 본인 부담 + 5년 전기료·보험료·정비비 + 5년 후 매각 잔여가치를 종합 평가합니다. EV는 운영 비용이 내연차 대비 30~50% 저렴해 5년 누적 절감액이 큽니다. 본인 사용 패턴 + 충전 인프라 + 자금 여력에 맞춘 결정이 표준입니다.
5. **다른 혜택(개소세·취득세·통행료) 추가 활용**: 보조금 외에 개소세 인하·취득세 감면·통행료 50% 감면·공영주차장 할인 같은 부수 혜택을 미리 점검합니다. 본인 등록 시점에 자동 적용 또는 별도 신청이 필요한 부분을 정리해 누락 없이 활용합니다.

## 자주 묻는 질문

**Q1. 내연차를 매도하지 않고 보유한 채 EV를 매수해도 전환지원금이 적용되나요?**
적용 안 됩니다. 전환지원금은 EV 신규 등록 시점에 내연차 폐차 또는 매도 증빙이 필수입니다. 매도 후 EV 매수 또는 동시 진행이 자격 조건입니다. 본인 사정상 내연차 유지가 필요하면 일반 EV 보조금만 적용됩니다.

**Q2. 캐스퍼 EV vs EV6 어느 쪽이 가성비 좋나요?**
캐스퍼 EV는 소형 + 도심 사용 + 본인 부담 적음 + 5년 가치 안정이 강점이고, EV6는 중형 + 장거리·가족 사용 + 더 큰 화면·기능이 강점입니다. 본인 사용 패턴 + 가족 인원 + 주행거리 요구에 맞춘 선택이 표준입니다.

**Q3. 6월 정보 공개 의무가 EV 매수에 어떤 도움이 되나요?**
6월부터 신차 EV 배터리 제조사·용량·전압 정보 공개 의무로 본인 사용 환경(주행거리·충전·온도)에 맞춘 EV 선택이 정확해집니다. NCM vs LFP 셀 선택, 보증 잔여, 5년 가치 평가가 더 명확해져 본인 만족도 높은 결정이 가능합니다.

**Q4. 보조금 마감 후 신청은 어떻게 되나요?**
지자체별 잔여 보조금 마감 후에는 다음 회차 보조금 추가 발표를 기다리거나 보조금 없이 자비 매수 결정이 됩니다. 다음 회차 추가 발표는 정부 정책 + 지자체 예산 상황에 따라 결정되고 확정적이지 않습니다. 6월 초 신청이 안전합니다.

**Q5. 전환지원금 외에 5년 의무 보유 조건이 같이 적용되나요?**
보조금 + 전환지원금 모두 5년 의무 보유 + 매각 시 잔여 비율 환수 조건이 적용됩니다. 2년차 매각 시 60% 환수, 3년차 40% 같은 계산 구조입니다. 본인 5년 사용 계획이 안정적이어야 보조금 활용 가치가 최대화됩니다.

## 마지막 한마디

EV 전환지원금 100만 원 + 5~6월 보조금 잔여 + 6월 정보 공개 의무 시행은 EV 매수 결정의 핵심 환경입니다. **본인 내연차 자격 확인 + 본인 거주지 잔여 보조금 + 6월 초 신청 + 본인 사용 환경 매칭**의 흐름으로 결정하시면 캐스퍼 EV·EV6·코나 EV 같은 인기 모델 매수 가능성이 안정됩니다. 5년 의무 보유 + 운영 비용 절감 + 잔여가치를 종합 평가해 신청 시점을 결정합니다.
