## 핵심만 먼저

Windows 10 노트북은 쓰임에 따라 대응 시점을 다르게 잡으면 됩니다. Windows 10 지원은 2025년 10월 14일에 끝났고, 그 뒤로는 일반적인 방식의 새 보안 패치가 나오지 않습니다. 온라인 뱅킹이나 업무 파일을 다루는 노트북이라면 이번 여름 안에 방향을 정해 두는 편이 안전합니다. 인터넷을 끊고 특정 프로그램만 돌리는 오프라인 서브 PC라면 지금처럼 더 써도 큰 문제가 없습니다. 무료로 신청할 수 있는 확장 보안 업데이트(ESU)가 2027년 10월 12일까지 시간을 벌어 주기 때문에, 당장 새 PC를 사야 하는 경우는 많지 않습니다.

## 지원 종료가 뜻하는 것

지원 종료는 노트북이 갑자기 멈춘다는 뜻이 아닙니다. Windows 10은 그대로 켜지고 설치된 프로그램도 돌아갑니다. 달라지는 부분은 보안 하나입니다. Microsoft는 2025년 10월 14일을 기점으로 Windows 10에 대한 정기 보안 업데이트와 기술 지원을 종료했습니다. 이후 새로 발견되는 운영체제 취약점은 별도의 확장 보안 업데이트에 가입하지 않는 한 더 이상 막히지 않습니다.

위험이 문제가 되는 이유는 시간에 비례해 쌓이기 때문입니다. 지원이 끝난 지 여러 달이 지나도록 큰 사고가 없었다고 해서 안전이 확인된 것은 아닙니다. 공격자 입장에서는 아직 막히지 않은 구멍을 찾아 쓰면 되고, 그런 구멍은 달이 갈수록 늘어납니다. 백신을 최신으로 유지해도 운영체제 자체의 빈틈까지 백신 소프트웨어로 온전히 메우기는 어렵습니다. "지금까지 괜찮았으니 계속 괜찮겠지"라는 판단은 위험을 뒤로 미뤄 두는 쪽에 가깝습니다.

## 내 노트북은 어느 쪽인가

같은 Windows 10 노트북이라도 무엇에 쓰느냐에 따라 위험의 크기가 크게 갈립니다. 아래 표로 지금 상황이 어느 칸에 들어가는지 먼저 가늠해 보면 판단이 빨라집니다.

| 사용 목적 | 위험도 | 권장 대응 | 결정 시점 |
| --- | --- | --- | --- |
| 온라인 뱅킹·공동인증서 | 높음 | 업그레이드 또는 ESU 신청 | 올여름 |
| 업무 문서·이메일·클라우드 | 높음 | 업그레이드 + 백업 습관 | 올여름 |
| 게임·유튜브·문서 작업 | 중간 | ESU로 시간 벌기 | 올해 안 |
| 물려받은 가족 서브 PC | 중상 | 계정 점검 + ESU | 올해 안 |
| 오프라인 전용(인터넷 차단) | 낮음 | 현행 유지 | 서두를 것 없음 |

가장 신경 써야 하는 쪽은 온라인 뱅킹과 공동인증서 앱을 자주 쓰는 노트북입니다. 은행·증권 앱은 최신 운영체제와 브라우저에 맞춰 갱신되기 때문에, 시간이 지날수록 Windows 10 환경에 대한 지원이 순차적으로 줄어들 수 있습니다. 실제 차단 일정은 은행마다 다르므로, 정확한 시점은 각 앱 공지에서 확인하는 편이 확실합니다.

회사 문서와 이메일, 클라우드 계정이 담긴 업무용 노트북도 감염 시 피해가 큽니다. 랜섬웨어에 걸리면 최근 작업물이 통째로 잠기고 업무 사고로 이어질 수 있어 우선순위가 높습니다. 백업을 대신 챙겨 줄 사람이 없는 프리랜서나 1인 사업자라면 위험은 더 커집니다.

게임과 유튜브, 간단한 문서 작업만 하는 개인용은 당장의 위협이 상대적으로 낮은 편입니다. 브라우저와 앱도 언젠가는 Windows 10 지원을 줄여 가므로 인터넷 사용이 조금씩 불편해질 수 있지만, 서둘러 바꿀 만큼 급하지는 않습니다.

부모님이 물려받은 서브 PC는 조금 더 조심스럽습니다. 가족 사진과 메신저 로그인 정보가 담겨 있으면 위험도가 업무 PC와 비슷하고, 보안 인식이 낮아 피싱 링크에 노출되기 쉽습니다. 결제 앱이나 자녀 계정까지 연결돼 있다면 관리 강도를 한 단계 높이는 편이 안전합니다. 반대로 인터넷을 아예 끊고 특정 프로그램 실행용으로만 쓰는 오프라인 노트북은 그대로 두어도 무방합니다. 오래된 장비·프로그램을 다루는 현장에서 실제로 이 방식이 널리 쓰입니다.

## 선택지 네 가지 비교

대응 방법은 크게 네 갈래입니다. 요건이 맞으면 Windows 11로 무상 업그레이드하는 길, 확장 보안 업데이트로 시간을 버는 길, 지금처럼 계속 쓰는 길, 새 PC로 교체하거나 다른 운영체제로 갈아타는 길입니다. 각 선택의 비용과 성격을 나란히 놓고 보면 자기 상황에 맞는 답이 보입니다.

| 선택지 | 비용 | 보안 업데이트 | 적합한 경우 | 유의점 |
| --- | --- | --- | --- | --- |
| Windows 11 무상 업그레이드 | 요건 충족 시 0원 | 계속 제공 | 사양이 맞는 노트북 | 요건 미달이면 불가 |
| 확장 보안 업데이트(ESU) | 무료(설정 동기화)~30달러 | 2027-10-12까지 | 당장 못 바꾸는 뱅킹·업무 PC | 임시 다리, 기능 추가 없음 |
| 지금처럼 계속 사용 | 0원 | 없음 | 오프라인·저위험 용도 | 시간이 갈수록 위험 누적 |
| 새 PC로 교체 | 기기값 | 계속 제공 | 사양 낮고 활용도 높은 경우 | 지출 크고 시기 조율 필요 |
| ChromeOS Flex·리눅스 전환 | 무료 | 새 운영체제가 담당 | 웹 위주로 쓰는 경우 | 데스크톱 전용 앱 제약 |

가장 깔끔한 답은 Windows 11 무상 업그레이드입니다. 사양만 맞으면 비용이 들지 않고 보안 업데이트도 계속 받습니다. 사양이 안 맞으면 ESU로 시간을 벌면서 교체 시점을 저울질하는 편이 현실적입니다. ChromeOS Flex나 리눅스는 오래된 노트북을 무료로 되살리는 선택이지만, 데스크톱 전용 프로그램을 쓰던 사람에게는 적응 비용이 따르므로 용도부터 확인하는 것이 좋습니다.

## 윈도우11로 갈 수 있나

Windows 11 업그레이드는 사양이 맞으면 비용이 0원입니다. 문턱은 하드웨어 요건에 있습니다. 2019년 무렵 이전에 산 노트북은 상당수가 이 요건을 넘지 못합니다. 설정에서 업데이트 화면을 열면 호환 여부가 안내되고, Microsoft가 제공하는 PC 상태 검사 앱으로도 확인할 수 있습니다.

| 항목 | 최소 요구사항 | 확인 방법 |
| --- | --- | --- |
| CPU | 64비트 2코어 이상, Microsoft 승인 목록(대체로 인텔 8세대·라이젠 2000 이후) | PC 상태 검사 앱 |
| 메모리(RAM) | 4GB 이상 | 설정 → 시스템 → 정보 |
| 저장 공간 | 64GB 이상 | 설정 → 시스템 → 저장소 |
| 보안 칩 | TPM 2.0 | 실행 창에서 tpm.msc |
| 펌웨어 | UEFI + 보안 부팅(Secure Boot) | 시스템 정보(msinfo32) |
| 그래픽·화면 | DirectX 12, 9인치·720p 이상 | 사양표 참고 |

여기서 가장 자주 걸리는 항목이 CPU와 TPM 2.0입니다. TPM은 메인보드의 보안 칩으로, 값을 켜지 않아 꺼져 있는 경우도 있으므로 바이오스(UEFI) 설정에서 활성화되어 있는지 확인해 볼 만합니다. CPU 세대가 목록에 없으면 다른 조건을 다 맞춰도 정식 업그레이드는 지원되지 않습니다. 이때는 무리해서 우회 설치를 시도하기보다 ESU나 교체 쪽을 검토하는 편이 뒤탈이 적습니다.

## ESU로 시간 벌기

확장 보안 업데이트(ESU)는 Windows 10에 남는 안전 마진을 만들어 주는 장치입니다. Microsoft는 개인 사용자에게도 ESU를 열어 두었고, 여기에 가입하면 지원 종료 뒤에도 중요·긴급 보안 패치를 계속 받습니다. 개인용 가입 방법은 세 가지입니다. Windows 백업으로 설정을 클라우드에 동기화하는 무료 경로, 1,000점의 Microsoft Rewards 포인트를 쓰는 경로, 그리고 1회 30달러(원화로는 환율에 따라 4만 원 안팎)를 결제하는 경로입니다. 유료 라이선스 하나로 같은 계정에 연결된 최대 10대까지 적용할 수 있습니다.

기간도 최근 넉넉해졌습니다. 개인용 ESU는 처음에 2026년 10월까지의 한 해짜리로 안내됐지만, Microsoft가 무료 연장을 추가하면서 커버리지가 2027년 10월 12일까지 늘었습니다. 이미 가입해 둔 기기는 별도 조치 없이 연장분이 자동으로 이어집니다. 늦게 가입해도 그사이 나온 누적 패치를 한 번에 받게 되므로, 첫 연결 때 재부팅이 여러 번 필요할 수 있습니다. 교육·기업용 볼륨 라이선스는 성격이 조금 달라, Pro·Enterprise·Education 같은 상업용 에디션은 최대 3년치(2028년 10월까지) ESU를 구매할 수 있습니다. 회사에서 지급한 노트북이라면 IT 담당자에게 지원 범위를 물어보는 편이 확실합니다. ESU는 어디까지나 임시 다리라는 점은 기억해 둘 부분입니다. 새 기능이 추가되지도, 일반 기술 지원이 되살아나지도 않습니다.

## 비용과 놓치기 쉬운 함정

대응을 정할 때 실제로 드는 돈은 선택마다 크게 다릅니다. Windows 11 업그레이드와 ChromeOS Flex 전환은 사양·용도만 맞으면 사실상 0원입니다. ESU는 무료 경로를 쓰면 역시 추가 비용이 없고, 유료로 가더라도 1회성 지출에 그칩니다. 부담이 큰 쪽은 새 PC 교체입니다. 사무·학습용 보급형과 게임·영상 편집용 고사양은 가격대가 크게 벌어지므로, 용도에 맞는 최소 사양을 먼저 정하고 예산을 잡는 편이 낫습니다. 신학기를 앞둔 시즌이나 세일 기간에 맞추면 같은 사양을 더 낮은 값에 구하기도 하니, 급하지 않다면 시기를 조율하는 선택도 합리적입니다.

놓치기 쉬운 함정도 몇 가지 있습니다. 첫째, Windows 10을 그대로 쓰면서 백신만 최신으로 유지하면 안전하다고 여기기 쉬운데, 운영체제 자체의 구멍은 백신으로 채워지지 않습니다. 둘째, 오프라인 전용이라 무조건 안전하다고 단정하기 어렵습니다. USB로 자료를 옮기는 과정에서 감염이 넘어오는 경로가 실제로 흔합니다. 셋째, 은행 앱은 자체 정책에 따라 특정 시점부터 Windows 10을 완전히 차단할 수 있으므로, 정확한 일정은 각 은행 공지에서 미리 확인해 두는 편이 안전합니다. 넷째, 이미 Windows 11로 올라갔더라도 방심은 이릅니다. Windows 11은 버전별로 수명 주기가 정해져 있어, 최신 버전으로 업데이트를 유지해야 지원이 계속 이어집니다. 결국 핵심은 하나입니다. 지금 내 노트북이 어떤 위험 칸에 있는지 확인하고, 그 칸에 맞는 대응만 제때 해 두면 됩니다.

## 자주 묻는 질문

### Q. Windows 11 업그레이드 요건이 안 맞는 낮은 사양 노트북, 새로 사야 하나

바로 새 PC로 갈 필요는 없습니다. 우선 무료로 신청할 수 있는 확장 보안 업데이트(ESU)로 2027년 10월까지 시간을 벌 수 있습니다. 인터넷 사용이 대부분이라면 ChromeOS Flex 전환도 시도해 볼 만합니다. 구글 계정으로 부팅되고 웹 기반 작업 대부분이 정상 작동하며, 오래된 노트북에서 체감 속도가 나아지기도 합니다. 자녀 학습용이나 문서·영상 확인용이라면 이 방식으로 몇 년을 더 쓸 수 있습니다. 뱅킹·인증서 앱이 꼭 필요하면 스마트폰이나 태블릿과 나눠 쓰면 부담이 줄어듭니다. 설치는 8GB 정도의 USB에 이미지를 담아 부팅 순서만 바꾸면 되고, 맞지 않으면 원래 환경으로 되돌릴 수도 있습니다.

### Q. 개인용 ESU를 지금 신청하면 2025년 10월부터 소급되나

개인용 ESU는 늦게 신청해도 업데이트 제공이 시작된 2025년 10월 이후의 보안 패치를 받을 수 있고, 커버리지는 프로그램 종료일인 2027년 10월 12일까지 이어집니다. Microsoft가 개인용 무료 연장을 추가하면서 당초 2026년 10월이던 종료 시점이 한 해 더 늘었습니다. 지금 신청하면 첫 연결 때 그동안 누락된 누적 업데이트가 한 번에 설치되므로 재부팅이 여러 번 필요할 수 있어, 시간 여유가 있을 때 진행하는 편이 낫습니다. 신청은 Microsoft 계정으로 로그인한 상태에서 설정의 업데이트 화면에서 진행하며, 무료 경로(설정 동기화)나 Microsoft Rewards 포인트, 1회 30달러 결제 중 하나를 고르면 됩니다.

### Q. 인터넷 뱅킹·공동인증서 앱은 언제까지 Windows 10에서 문제없이 되나

은행·증권마다 시점이 다르지만, 앞으로 Windows 10 환경에 대한 지원은 순차적으로 줄어드는 흐름입니다. 앱이 최신 브라우저와 운영체제에 맞춰 갱신되기 때문입니다. 자주 쓰는 은행 앱 공지에서 지원 브라우저·운영체제 안내를 미리 확인해 두면 실제 차단 전에 준비할 시간이 생깁니다. 스마트폰 앱과 함께 쓰는 습관을 들이면 PC 쪽이 막혀도 급하게 대체하기 쉽습니다. 공동인증서는 클라우드 저장 기능을 켜 두면 새 기기로 옮기기도 한결 간단해집니다.

### Q. 리눅스나 ChromeOS Flex로 바꾸면 기존 파일과 프로그램은 어떻게 되나

파일은 외장하드나 USB, 클라우드에 백업해 두면 새 운영체제에서도 그대로 열 수 있습니다. 걸림돌은 프로그램 쪽입니다. ChromeOS Flex는 웹 앱 위주로 돌아가서 아래아한글이나 데스크톱용 오피스는 설치되지 않습니다. 대신 한컴 웹, 오피스 웹, 구글 문서 같은 웹 버전으로 상당 부분 대체할 수 있습니다. 리눅스는 자유도가 높은 대신 뱅킹 앱과 일부 게임을 지원하지 않는 경우가 많아, 사용 목적을 먼저 정하고 옮기면 시행착오가 줄어듭니다. 옮기기 전에 자주 쓰는 프로그램을 적어 두고 각각의 웹·리눅스 대체재가 있는지 확인해 두면 후회가 적습니다.
