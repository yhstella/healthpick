## 편집 기준과 출처

- 정신건강 글의 위기 연락처는 전용 조회 도구에서 확인된 국내 연락처·링크만 사용했다. 확인되지 않은 문자·운영시간·비밀 보장 정보는 덧붙이지 않았다. 해외 자료에 적힌 미국 연락처를 한국 독자에게 그대로 안내하지 않는다.
- 위험 신호는 진단표가 아니며, 항목이 없으면 안전하다고 판단할 수 없도록 썼다. 우울·수면·통증을 무조건 정신질환이나 노화로 단정하지 않는다.
- [NIMH 위험 신호](https://www.nimh.nih.gov/health/publications/warning-signs-of-suicide), [NIMH 돕는 행동](https://www.nimh.nih.gov/health/publications/5-action-steps-to-help-someone-having-thoughts-of-suicide), [MedlinePlus 노년기 우울증](https://medlineplus.gov/ency/article/001521.htm)의 해당 본문을 확인했다.
- 임신 준비의 엽산 일반 권고는 [USPSTF](https://www.uspreventiveservicestaskforce.org/uspstf/recommendation/folic-acid-for-the-prevention-of-neural-tube-defects-preventive-medication)를 미국 권고로 명시했다. 고위험군에 같은 용량을 적용하거나 고용량을 직접 지시하지 않는다.
- [ASRM 자연 임신 준비 의견서](https://www.asrm.org/practice-guidance/practice-committee-documents/optimizing-natural-fertility-a-committee-opinion-2021/)와 [난임 평가 의견서](https://www.asrm.org/practice-guidance/practice-committee-documents/fertility-evaluation-of-infertile-women-a-committee-opinion-2021/), [NHS 보충제 안내](https://www.nhs.uk/best-start-in-life/pregnancy/vitamins-and-supplements-in-pregnancy/)의 대상과 예외를 구분했다. URL 말미의 연도가 논문 표제의 연도와 다를 수 있으므로 URL을 임의로 만들어서는 안 된다.
- 난소 낭종의 국내 자료는 국가건강정보포털과 서울아산병원 원문을 확인했다. [RCOG의 폐경 후 지침 개정](https://www.rcog.org.uk/guidance/browse-all-guidance/green-top-guidelines/ovarian-cysts-in-postmenopausal-women-green-top-guideline-no-34/)은 2025년 12월 5일 검토·개정된 안내다. '한쪽·단방성·단순·3cm 이하'라는 조건을 생략하거나 국내 모든 환자에게 같은 기준을 적용하지 않는다.
- 낭종의 기존 피임약 설명은 [RCOG 폐경 전 안내](https://www.rcog.org.uk/for-the-public/browse-our-patient-information/ovarian-cysts-before-the-menopause/)에서 확인했다. 이미 생긴 단순 낭종을 사라지게 하는 효과와 다른 처방 목적은 구분한다.

이번 출처 확인과 편집은 실제 의사의 감수가 아니다. 감수 기록이나 검토자·감수일은 새로 만들지 않았다. 재작성한 3편은 중복된 본문·frontmatter FAQ를 제거해 두 곳의 답이 달라지는 위험도 줄였다.

## 검증 범위

`npm test` 19개가 통과했고 정적 빌드는 743페이지로 성공했다. 수정한 4편의 출력 검사와 기존 공개 경로 회귀 검사 7개 묶음도 통과했다. 검색 데이터는 91편, 건강 태그 페이지는 348개다. 사이트맵 101개 중 건강 URL은 91개이고 건강 글의 수정일 누락은 0개다. RSS 50개도 모두 건강 글이다.

검증 스크립트는 원래 발행일·canonical 보존, 수정일, 직접 출처의 본문·HTML 연결, 실제 수정 문장, 의료 감수 미주장, 원본 Markdown·OG 출력을 검사한다. 이는 의학적 주장이 모두 타당하다는 자동 판정이 아니다. 운영 URL 검사는 배포 후 별도 결과로 남긴다. 로그와 재현 스크립트는 소유자의 `output/healthpick-2026-10-23-followup` 작업 폴더에 둔다.

`npm run audit:content` 기준 건강 글은 91편을 유지한다. 기관 홈페이지 참조를 포함한 글은 54편에서 53편으로 줄었다. 53편은 기계적 검토 목록이며 전부 '근거 없음'이라는 뜻은 아니다.

GSC의 기존 4개 URL 요청을 반복하지 않았으며, 앞선 사이트맵 제출이나 요청 접수를 색인 회복의 증거로 바꾸어 기록하지 않는다. 기존 미추적 `scripts/quality-audit.mjs`는 수정·커밋하지 않는다.

## 이어서 볼 사항

1. 남은 글의 홈페이지 링크를 실제 주장에 대응하는 문서로 교체하고, 단정적인 치료·검사 간격부터 검토한다.
2. 고혈압 글의 '2026 지침'은 제목만 보고 허위라고 판단하면 안 된다. 학회 공식 게시판의 [제6판 수정본](https://www.koreanhypertension.org/reference/guide?idno=10446&mode=read)과 [하이라이트 논문 안내](https://www.koreanhypertension.org/reference/guide?idno=10447&mode=read)가 실제로 공개된 것을 확인했다. 새 지침을 다루는 글은 그 원문과 주장을 대조해야 한다.
3. 레거시 `scripts/verify-batch.mjs`의 글자 수·표 개수·'습니다' 횟수는 품질이나 의료 안전의 증거가 아니다. 이번 검증의 통과 조건으로 사용하지 않았다.
