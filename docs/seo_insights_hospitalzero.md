## 1. 사이트 네트워크 구조

```
hospitalzero.co.kr (본 도메인)              ─ 약 11,000편
├── 메뉴 카테고리: 치과 / 한의원 / 정형외과 / 동물병원 / 홈페이지
├── 실제 콘텐츠 비중:
│   ├── "홈페이지" 카테고리 = 잡다 (금시세·정부사이트·협회·이벤트)
│   └── 병원 4종 카테고리 = 메뉴만 있고 거의 비어있음 (선점용)
└── 글 길이: 150~200자 짧은 미리보기 (저비용 hub)

effect.hospitalzero.co.kr (서브 도메인)     ─ 약 7,600편
├── 효능백과: 5,000편 (4,500자 풀콘텐츠)
└── 건강상식: 2,600편 (질병·증상·치료)

━━━ 총 약 18,000편, 1인 운영 (작성자 cho) ━━━
```

### 도메인 분리 전략의 의도

| 도메인 | 역할 | 콘텐츠 형식 | 목적 |
|---|---|---|---|
| 본 도메인 | 도메인 권위 빌딩 | 짧은 hub 글 | 저비용으로 인덱스 자산 폭증 |
| 서브 도메인 | 수익 창출 | 4,500자 풀콘텐츠 | YMYL 격리 + 본 도메인 페널티 보호 |

**핵심 인사이트**: YMYL(건강·의료) 양산형은 도메인 권위 0에서는 절대 못 살아남는다. hospitalzero는 본 도메인에 잡다 콘텐츠로 권위 빌딩 → 권위 쌓이자 서브에서 YMYL 양산.

## 4. 글자수 4,500자가 최적인 수학적 근거

```
4,500자 ÷ 한국어 평균 읽기 속도(700자/분) = 6.4분
   ↓
Dwell Time 6.4분 = 한국 SERP 상위 1~3위 평균 dwell time
   ↓
Google 랭킹 신호: dwell time = top 5 신호 중 하나
   ↓
4,500자 = 랭킹 진입 티켓
```

## 7. 신규 사이트 청사진 — dailylab.co.kr (제안)

### 작명 원칙 5가지

1. **버티컬 중립** — 한 분야 묶이면 확장 막힘
2. **서브도메인 친화** — `health.*`, `money.*` 폭격 위해
3. **짧고 영문 5~10자** — 검색결과 URL 클릭률 ↑
4. **.co.kr 우선** — 일반인 신뢰도·EEAT 신호
5. **권위/완결성 단어** — lab/base/hub/note/all

### 서브도메인 청사진

```
dailylab.co.kr (본)            ─ 잡다 정보 + 도메인 권위 빌딩
├── health.dailylab.co.kr      ─ 효능·증상·질병 (YMYL, 7,000편)
├── money.dailylab.co.kr       ─ 정부지원금·재테크·세금 (CPC 최상)
├── job.dailylab.co.kr         ─ 자격증·연봉·취업
├── pet.dailylab.co.kr         ─ 반려동물 (hospitalzero 미점령 영역)
└── tip.dailylab.co.kr         ─ 생활팁·DIY (대량 long-tail)
```

### 사이트 표시명

| 위치 | 표시명 |
|---|---|
| 헤더 로고 | DailyLab |
| 본문·푸터 | 데일리랩 |
| 메타 title | 데일리랩 — 매일 검증한 생활 정보 |
| 글 하단 byline | DailyLab 검증팀 (1인이지만 "팀" 표기로 EEAT 위장) |

### 도메인 등록 전 체크리스트

1. **whois 확인** — kisa.or.kr 또는 가비아·후이즈
2. **dailylab.com 동시 확보 검토** — 추후 분쟁 위험 회피
3. **상표 검색** — kipris.or.kr에서 "데일리랩" 등록 상표 확인
4. **이전 사용 이력** — archive.org에서 도메인 과거 이력 검사 (스팸·도박 운영 도메인은 영구 페널티)
5. **villagebaby/ruuve와 운영자 정보 분리** — 사업자등록·계좌·도메인 등록자 모두 분리. WHOIS 비공개 옵션 필수

## 9. 양산형 운영 주의 사항 (2026.05 시점)

### 리스크

1. **AI Overview / SGE** — 효능·증상·복용법 키워드는 SGE 직격탄. CTR 30~50% 감소.
2. **Helpful Content + March 2024 Core Update 잔여 효과** — 양산형 신규 도메인은 더 강하게 거름.
3. **선점 효과 끝남** — 효능 키워드 위에 hospitalzero 같은 선점자가 이미 있음.
4. **EEAT 없는 YMYL은 언제든 한 방 디인덱싱** — 다음 코어 업데이트에서 hospitalzero가 살아남는다는 보장도 없음.

### 회피 전략

1. **AI Overview 회피 키워드 선별** — "가격·후기·비교·2026 신상" 키워드로 무게중심 이동
2. **Claude Sonnet 4.5 사용** — 양산형 티 안 남
3. **EEAT 신호 박기** — 출처·감수자·작성자 정보
4. **별도 도메인 + 운영자 정보 분리** — villagebaby/ruuve 브랜드 자산 보호
