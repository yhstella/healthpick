# Healthpick 혈당 원고 교정과 통합

## 고쳐야 했던 문제

일반 식사 후 자가 혈당을 75g 경구당부하검사의 진단 기준에 그대로 대입하는 오류를 확인했다. 뒤 문단에서 정맥 채혈을 안내하더라도 제목 아래 요약과 표가 이미 같은 검사처럼 설명해 오해를 만들었다. 공복혈당 105 글 두 편은 다른 숫자의 별도 질문이라기보다 전단계의 식사·운동·감량·재검을 반복했다. 같은 문답이 frontmatter와 본문에 중복되기도 했다.

당화혈색소 글에는 '6.5% 미만이므로 약물 시작 대상이 아니다'라는 문장과 예방 약물 상담이 가능하다는 문장이 함께 있었다. 식단 글은 모든 사람에게 적합한 탄수화물 비율이 있는 것처럼 설명하면서 개인별 조정이라는 단서를 덧붙였다. 단서를 더하는 대신 잘못된 일반화를 고쳤다.

## 편집 범위

| 기존 주소의 식별자 | 처리 |
| --- | --- |
| `공복혈당-110-당뇨-전단계` | 공복혈당 100~125의 검사 확인과 생활관리 안내로 재작성. 두 105 글의 질문과 태그를 통합 |
| `식후혈당-220-공복-95-가족력-40대-약-시작-기준` | 일반 식사 후 자가 측정, 75g 검사, 증상을 동반한 무작위 혈장검사를 구분 |
| `당뇨-식단의-진짜-핵심` | 식품 종류뿐 아니라 양·구성과 약물 조건을 설명. 고정된 영양소 비율, 식사 순서의 과장, 임의 식사 제한을 수정 |
| `당화혈색소-6-1-당뇨-진단-기준` | 전단계와 확진, 추가 검사와 추적을 구분. 2019 지침 참조를 2025 국내 원문으로 갱신하고 약물 상담의 조건을 설명 |
| 두 `공복혈당-105-당뇨전단계-*` 글 | 소스는 삭제하지 않고 `draft: true`로 통합 보관. 본문·raw·OG는 해당 통합 글로 영구 이동 |

새 글 발행이 아닌 기존 네 원고의 재작성과 두 중복 글의 통합이다. 원래 URL과 발행일을 유지하고 실제 수정일만 2026-10-23으로 기록한다. 실제 의료 감수는 하지 않았으며 감수 기록을 새로 만들지 않는다. 생활요법의 목표와 연구 결과를 개인의 정상화 보장으로 바꾸지 않는다.

## 국내 원문 대조

[대한당뇨병학회 2025 전문](https://diabetes.or.kr/bbs/download.php?code=guide&number=1522)의 진단·선별, 예방, 의학영양요법을 대조했다. 이전 글의 모든 설명이 틀렸다고 취급하지는 않는다. 6.1%에서 경구당부하검사를 검토하는 근거는 있지만, 현행 선별 권고의 '전단계 결과이면서 당뇨병이 의심되는 경우 다른 방법의 검사 추가'라는 조건을 보존한다. 전단계에서 메트포민을 고려할 수 있다는 권고 역시 과체중·비만 성인에 대한 제한적 권고이며 모든 전단계에 처방하라는 뜻이 아니다.

검사와 생활관리의 일반 설명은 NIDDK, 탄수화물 계산과 예방 실천은 CDC, 혈당측정기의 사용 조건은 FDA의 직접 문서와 대조하고 각각 본문에 연결한다. 오래된 기관 홈페이지나 자료실 링크만 남기지 않는다. 임신부의 별도 기준을 일반 성인의 표에 섞지 않고, 이미 치료 중인 사람이 낮아진 수치를 약 중단의 근거로 읽지 않도록 했다.

## 주소 연결

기존 `fasting-glucose-118-a1c-5-9-prediabetes` 영문 주소는 존재하지 않는 한글 주소로 이동한 뒤 최종 404였다. 해당 한글 주소도 직접 404임을 확인했다. 질문에 맞는 공복혈당 통합 안내로 각각 직접 이동하도록 고친다. 알려지지 않은 raw·OG 주소를 추측해 새 규칙을 만들지는 않는다.

새 한글 source와 목적지는 앞선 운영 검증에서 확인한 퍼센트 인코딩 형태로 지정한다. 기존 고혈압 통합 규칙과 관계없는 리다이렉트는 유지한다. 삭제·통합 주소를 관계없는 홈으로 보내지 않으며, 영구 이동과 목적지 200을 운영에서 모두 확인해야 한다.

## 검증과 Claude 인계

테스트 30개가 통과했다. 추가 여섯 검사는 발행일·감수 기록, 통합 보관·태그, 인코딩 경로와 과거 118 주소, 직접 출처의 본문 연결, 검사 구분, 개인별 영양·치료 조건을 확인한다. 임상적 정확성을 자동 승인하는 테스트는 아니다.

수정 전 전체 361편의 소스·정적 본문·구조화 데이터를 기준으로 저장했다. 수정 후 공개 359편 중 네 원고를 제외한 355편이 기준과 일치했다. 통합 보관 글은 모든 정적 HTML·홈·목록·검색·XML·LLM 안내에서 빠졌고 본문·raw·OG 파일도 생성되지 않는다. 742페이지 정적 빌드가 통과했으며 사이트맵 99개 중 건강 89개, 건강 수정일 누락 0개다. 수정 네 글의 실제 수정일이 반영됐고 RSS 50개는 모두 건강 글이다.

공개 건강 글은 91편에서 89편, 통합 보관은 기존 한 편을 포함해 세 편이 된다. 기계적 기관 홈페이지 참조 검토 대상은 49편에서 46편으로 줄었다. 이는 출처 적절성이나 실제 감수 완료를 의미하지 않는다.

빌드와 운영 주소·XML·화면·GSC 확인 결과는 소유자의 `output/healthpick-2026-10-23-glucose` 폴더에 기록한다. 색인 요청은 이미 요청한 URL에 반복하지 않고, 새로 교정한 대표 글의 상태를 확인한 뒤 구분해 기록한다. 요청 접수를 실제 색인이나 유입 회복으로 표현하지 않는다.

첫 운영 검증에서 수정 네 글의 본문·원문·메타데이터가 로컬 출력과 일치했고, 이전 고혈압 통합을 포함한 15가지 주소의 영구 이동과 최종 200이 확인됐다. 운영 XML도 99개/건강 89개/수정일 누락 0개였다. 화면 확인 후 공복혈당 글 제목의 불필요한 줄바꿈을 줄이도록 제목만 짧게 다듬었다. 실제 의료 감수나 검색 성과가 확인됐다는 뜻은 아니다.

Claude는 같은 검사 결과의 숫자만 바꾼 글을 추가하지 않는다. 공복혈당, 당화혈색소, 식후 자가 측정처럼 검사와 독자의 다음 행동이 다를 때만 독립 안내를 둔다. 요약·표·FAQ·본문 전체에서 검사 이름과 단위를 함께 확인하고, 식단·감량·운동의 고정 목표를 모든 사람에게 적용하지 않는다. 통합 보관본은 다시 공개하지 않는다.

미추적 `scripts/quality-audit.mjs`는 수정하거나 커밋하지 않는다. 자동 대량 발행은 재개하지 않는다.
