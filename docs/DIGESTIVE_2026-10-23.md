## 구체적인 편집 기준

1. '철분제를 먹으면 어두운 변이 생길 수 있다'와 '철분제 복용자의 검은 변은 모두 정상이다'는 다르다. 특징을 설명할 수는 있지만 특징이 없으면 출혈도 없다는 역명제를 만들지 않는다. 출혈은 통증 없이 발견되기도 한다.
2. 물에 번지는 색·휴지 색·냄새나 며칠 약을 끊는 시험으로 원인을 판정하게 하지 않는다. 제품·복용 시각과 증상은 의료진에게 전달할 정보다. 출혈이 의심되면 검진용 잠혈검사를 먼저 기다리는 순서도 피한다.
3. 검고 타르 같은 변·혈변·복통의 신속한 상담과, 실신·심한 어지럼·숨참·식은땀·쇠약을 동반한 응급 상황을 구분한다. 토혈이나 커피 찌꺼기 같은 구토는 다른 증상이 없어도 즉시 평가가 필요하다.
4. 흉통·명치 통증의 전형적 지속 시간은 최소 대기 시간이 아니다. 나이가 젊거나 알려진 심장병이 없어도 새 응급 증상을 체기로 단정하지 않는다. 해외 자료의 긴급 번호는 국내 안내에 그대로 복사하지 않았다.
5. 약을 일정 기간 처방해 반응을 보는 진료와, 진료 전에 독자가 스스로 약을 몇 주 시험하는 순서를 구분한다. 처방 중 악화하면 약 복용 기간이 끝날 때까지 기다리지 않는다. 반응이 있었다고 진단이 확정되는 것도 아니다.
6. 국가검진의 연령·주기를 증상 진료나 병변별 추적 기준으로 대신하지 않는다. 새 증상, 출혈, 삼킴 곤란, 반복 구토, 체중 감소, 빈혈 등의 정보를 보고 평가한다. 위내시경 외 검사가 먼저 필요할 수도 있다.
7. 내시경에서 본 모습과 조직검사는 같은 정보가 아니다. 위축·장상피화생을 모두 암으로 진행하는 상태처럼 쓰거나 모두에게 같은 추적 간격을 주지 않는다. 확인된 헬리코박터 감염의 치료와 별도 추적을 함께 점검한다.
8. PPI 장기 복용은 처방 목적과 출혈 위험을 확인한다. 증상 호전이나 부작용 기사만으로 중단시키지 않고, 모두에게 반드시 점진 감량해야 한다는 규칙도 만들지 않는다.
9. 기능성 소화불량을 식사 반응만으로 진단하지 않는다. 필요한 식품을 유지하며 개인별 유발 요인을 살피고, 제한 식품이 늘거나 체중이 줄면 진료·영양 상담으로 연결한다. 식사일기를 완성해야만 상담할 수 있다는 조건을 두지 않는다.
10. 제균 후의 요소호기검사·대변항원검사와 혈액 항체검사, 검진용 잠혈검사는 목적이 다르다. 검사 일정을 설명하면서 약을 임의 중단하거나 남은 항생제를 재복용하게 하지 않는다. 제균 확인과 기존 궤양·위축 등의 추적도 서로 다른 과제다.

본문과 frontmatter의 중복 FAQ는 네 교정본에서 제거했다. 필요한 답은 본문에 한 번 배치하고 출처를 해당 설명 가까이 연결한다. '진료 문턱', '결정선', '대개 정상' 같은 표현 대신 독자가 현재 무엇을 해야 하는지 직접 썼다.

## 검증과 후속 운영

테스트 60개가 통과했다. 새 아홉 검사는 원래 날짜·감수 미주장, 직접 출처, 출혈 자가 판정과 진료 지연 방지, 개별 약물·추적 판단, 식사 제한, 제균 확인 검사, 내부 링크와 Markdown 표시를 다룬다. 문자열·렌더링 검사는 의학적 타당성의 자동 승인이 아니다.

751페이지 정적 빌드가 통과했고 전체 공개 360편 중 수정 대상 밖 355편의 소스·본문·구조화 데이터·raw·OG가 일치한다. 기존 공개 URL과 루트 Vercel 설정을 유지했다. 새 글의 HTML·raw·OG 및 새 태그 페이지 3개 외 정적 경로의 추가·누락은 없다. raw 정적 헤더 규칙은 360개이며 기존 359개 규칙도 유지된다. 목차 링크 5112개가 실제 앵커와 연결된다.

사이트맵 100개 중 건강은 90개이며 건강 lastmod 누락은 0개다. 네 교정본과 새 글에 실제 날짜가 반영됐고 RSS 50개는 모두 건강 글이다. 새 글은 홈·건강 목록·아카이브·LLM 안내에서도 발견된다. 공개면에서 내린 다른 카테고리 270편은 기존 noindex 상태를 유지한다.

전체 원고·정적 출력·XML·운영 확인과 화면 증거는 소유자의 `output/healthpick-2026-10-23-digestive`에 저장한다. 원고 교정 외 기존 파일과 라우팅을 보존하고, 새 글은 홈·건강 목록·아카이브·검색·RSS·사이트맵에서 발견할 수 있어야 한다. 개인 계정이나 GSC 화면은 공개 저장소에 넣지 않는다.

건강 소스는 94개, 공개 90개, 보관 초안 4개다. 홈페이지 참조의 기계적 검토 대상은 41편에서 38편으로 줄었다. 이는 나머지 38편의 오류 확정이나 다른 원고의 검증 완료를 의미하지 않는다. 현재 내용의 실제 의료 감수 기록은 공개 건강 글 90편 모두 없다.

색인 요청 수락과 실제 색인·노출·유입은 구분한다. 이미 요청한 URL을 반복 제출하거나 새 글을 냈다는 이유만으로 색인 회복을 주장하지 않는다. 자동 대량 발행과 보관 원고 재공개는 재개하지 않는다. 다음에는 호흡기 글의 2주·3주·8주 설명이 원인 단정이나 추가 자가관리 대기 조건으로 바뀌었는지 검토한다.
