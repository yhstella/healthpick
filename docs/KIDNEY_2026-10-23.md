# Healthpick 신장기능 글 작성과 알부민뇨 글 교정

## 이번 작업

앞선 `a42cea35` 배포 이후 새 글 1편을 작성하고 기존 글 1편을 재작성했다. 글 수를 늘리기 위한 숫자 변형이 아니라, 검진에서 처음 받은 eGFR 결과와 당뇨병 진료 중 UACR 결과라는 서로 다른 질문을 다룬다.

| 구분 | 제목과 경로 | 핵심 내용 |
| --- | --- | --- |
| 새 글 | 건강검진에서 eGFR이 낮으면 만성콩팥병인가요? `/health/건강검진-egfr-낮음-재검-만성콩팥병/` | 혈액·소변 지표의 차이, 지속성 확인, 재검 준비와 급성 악화의 진료 신호 |

새 글 발행일은 실제 작성일인 2026-10-23이다. 기존 글의 URL과 2026-05-29 발행일은 유지하고 수정일만 2026-10-23으로 기록한다. 서로 필요한 대목에서 내부 링크를 연결했다. 중복 frontmatter·본문 FAQ는 기존 글에서 제거했다. 실제 의료 감수 기록은 만들지 않았다.

## 원문 대조에서 바로잡은 판단

편집 초기에 국제 지침의 일반 성인 의뢰 예시만 보고 기존의 '당뇨병 환자의 알부민뇨 또는 eGFR 60 미만에서 협진' 문장을 지나친 일반화로 판단했다. 국내 원문을 확인하니 이 조기 협진 권고가 실제로 있어 배포 전 초안을 바로잡았다. 기존 권고 자체를 허위로 취급하거나, eGFR 30까지 협진을 미루도록 바꾸면 안 된다.

- [대한신장학회 2023 당뇨병콩팥병 지침 원문](https://ksn.or.kr/bbs/skin/publication/download.php?code=guideline_k&number=2224)의 제2장과 [진료지침위원회의 지침 소개](https://www.ekjm.org/journal/view.php?doi=10.3904/kjm.2023.98.6.270)를 대조했다.
- 국내의 당뇨병 대상 조기 협진 권고를 본문에 직접 연결한다. 한 번의 검사로 확진하는 것, 협진 필요성을 상담하는 것, 응급 진료가 필요한 것을 나누어 설명한다.
- [KDIGO 2024 지침](https://kdigo.org/wp-content/uploads/2024/03/KDIGO-2024-CKD-Guideline.pdf)의 만성 여부 평가와 [권고 요약](https://kdigo.org/wp-content/uploads/2026/05/KDIGO-2024-CKD-Guideline-Summary-Recommendations-and-Practice-Points.pdf)의 약물 사용 조건을 확인했다. 정상 혈압이면 치료가 필요 없다는 결론도, 단일 경계값이면 자동으로 약을 추가한다는 결론도 쓰지 않는다.
- 지침의 연도, 대상, 조건을 구분한다. '최신 지침'이라는 말만 붙이거나 서로 다른 학회의 기준을 한 표에 섞지 않는다.

## 표현과 독자 행동

새 글에는 검진표의 크레아티닌·eGFR·UACR을 구분하는 짧은 표를 넣었다. 검사값을 정상으로 만들려는 자가 약물 중단이나 수분 섭취 요령 대신, 이전 검사와 복용약·보충제·최근 몸 상태를 가져가도록 안내한다. 만성 여부의 관찰 기간을 '진료를 기다릴 기간'으로 읽지 않도록 구분했다.

기존 글은 기호로 이어 붙인 제목과 반복 설명을 줄였다. UACR의 mg/g과 다른 단위를 혼동하지 않도록 하고, '당뇨 5년차'만으로 원인·치료·의뢰가 정해지지 않는다고 설명한다. 직접 출처는 각각 5개이며 모두 본문에서도 연결한다. 출처 수는 의학적 검증 완료나 의사 감수의 증거가 아니다.

## 발행과 검증

테스트 19개와 746페이지 정적 빌드가 통과했다. 새 글과 수정 글의 H1·canonical·발행일·출처 연결·내부 링크·감수 기록 없음 표시를 출력물에서 확인했다. 새 글은 홈·건강 목록·아카이브·검색 데이터·RSS·사이트맵에 포함됐다. 사이트맵은 102개 중 건강 URL 92개이며 건강 글 수정일 누락은 0개, RSS 50개는 모두 건강 글이다.

운영 배포와 실제 화면은 이어서 검증하며 최종 결과는 소유자의 `output/healthpick-2026-10-23-kidney` 작업 폴더에 기록한다. 테스트는 도구·메타데이터 회귀 검사이지 원고의 의학적 타당성을 자동 판정하는 검사가 아니다.

공개 건강 글은 91편에서 92편으로 늘고, 기관 홈페이지 참조를 포함한 기계적 검토 대상은 51편에서 50편으로 줄었다. 이 수치를 출처가 전혀 없는 글의 수나 의료 감수 미완료 글 수와 혼동하지 않는다.

## Claude 인계

1. 국내 지침을 먼저 찾아 대상과 권고의 강도를 확인한다. 국제 지침과 다르다는 이유만으로 기존 국내 기준을 삭제하지 않는다.
2. 같은 숫자의 변형 글을 추가하지 않는다. 이번 두 글처럼 질문이 다를 때만 구분하고 독자가 이동할 이유가 있는 내부 링크를 둔다.
3. 제목·본문·요약·FAQ를 함께 확인한다. 본문만 고치고 이전의 자동 처방·일률적 의뢰 문구를 FAQ에 남기지 않는다.
4. 실제 감수는 내용에 대응하는 검토자·날짜·기록을 확보한 뒤에만 등록한다. 이번 편집을 의료 감수로 재포장하지 않는다.
5. 색인 요청 접수, 사이트맵 제출 성공, 실제 색인, 검색 클릭은 서로 다른 상태로 보고한다. 기존 URL에 같은 요청을 반복하지 않는다.

기존 미추적 `scripts/quality-audit.mjs`는 수정하거나 커밋하지 않는다. 자동 대량 발행도 재개하지 않는다.
