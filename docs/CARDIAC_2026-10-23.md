# Healthpick 심박수와 심장 증상 원고 교정

## Claude에게 전달할 핵심

응급 증상의 전형적인 지속 시간과 독자가 집에서 기다려야 하는 시간을 구분해야 한다. 기존 관상동맥질환 글은 흉통이 20~30분 이어지는 상황을 본문·FAQ·주의사항에서 반복해, 그 시간이 지나기 전에는 도움을 요청하지 않아도 되는 것처럼 읽힐 여지가 있었다. 기존 카페인 글의 '5분 이상'과 진료 전 2주·두 달의 생활관리 기간도 같은 관점에서 교정했다. 증상·현재 상태를 기준으로 행동을 안내하고 숫자를 기다리는 조건으로 만들지 않는다.

좋았던 내용은 유지했다. 기존 글에도 흉통·호흡곤란·실신의 응급 안내, 정상 심전도의 한계, 워치 알림만으로 약을 복용하지 말라는 설명이 있었다. 이번 교정이 최초로 모든 안전 정보를 추가한 것처럼 표현하지 않는다. 글의 문제를 유입 부진의 유일한 원인이라고 확정할 근거도 없다.

이번 차수는 신규 글 추가가 아니라 네 기존 원고 교정과 한 중복 원고 통합이다. 안정 시 측정값, 반복되는 두근거림, 기기의 이상 알림은 독자의 질문과 다음 행동이 달라 각각 유지했다. 단순히 같은 주제라는 이유로 모두 한 편에 넣지도 않고, 수치·연령·커피 잔 수만 바꾼 글을 늘리지도 않는다.

## 구체적인 편집 피드백

1. 성인 맥박 60~100의 일반 범위는 개인의 심장 질환 배제 기준이 아니다. 95를 곧바로 빈맥이라고 부르지 않되 정상 숫자로 증상을 무시하게 해서는 안 된다. 심박수가 100을 넘을 때까지 응급 대응을 보류시키지 않는다.
2. 커피 세 잔을 300mg으로 고정하지 않는다. 잔 크기·제품·추출 방식이 다르며, FDA의 400mg 설명도 개인별 안전선이나 권장 섭취 목표가 아니다. 임신·수유·질환·약물의 조건을 함께 보존한다.
3. 카페인 감량 뒤 수치가 내려갔다고 원인이 확정되거나, 그대로라고 카페인이 무관하다고 증명되는 것은 아니다. 여러 생활 요인을 동시에 바꾼 전후 비교는 진단 검사가 아니다.
4. 두근거림이 반복되면 상담할 수 있다. 2주가 되거나 2~3주치 기록을 완성해야 진료받는다는 순서를 만들지 않는다. 현재 증상이 멎지 않거나 응급 동반 증상이 있는 경우와 지금은 편안하지만 반복되는 경우를 분리한다.
5. 정상 심전도가 간헐적 부정맥을 모두 배제하지는 않는다. 그렇다고 모두에게 24시간 또는 24~48시간 홀터 검사를 고정해서 권하지 않는다. NICE의 발작성 심방세동 의심 상황과 증상 간격에 따른 기록 기간이라는 조건을 보존한다.
6. IHRN은 광학 맥박 자료를 활용한 자동 알림이고 ECG는 직접 기록한 전기 신호다. 심초음파는 구조·기능 평가이지 심방세동 리듬을 확진하는 심전도와 같은 검사가 아니다. 알림과 확인된 심방세동, 다른 장치로 발견된 무증상 리듬 연구의 위험도를 섞지 않는다.
7. '대규모 연구들에서'라는 표현만으로 정확도·위양성·뇌졸중 위험 배수를 제시하지 않는다. 기기·연구 대상·확인 방법이 다르면 동일한 성능이나 위험으로 옮겨 쓸 수 없다. 이번 안내에서 불필요한 고정 배수와 비교 단정을 제거했다.
8. 흉통의 전형적인 지속 시간은 최소 대기 시간이 아니다. 쉬면 잠깐 좋아지는 흉통도 확인이 필요하다. 증상이 있는 사람에게 정기 검진이나 운동 부족 교정을 진료의 대안으로 제시하지 않는다.
9. 예방 식단 하나가 가장 중요하다고 우선순위를 단정하거나 '하루 1~2잔'을 모든 사람의 안전한 음주량처럼 반복하지 않는다. 생활관리가 필요한 약물치료를 대신한다는 인상을 주지 않는다.
10. 본문과 frontmatter의 같은 FAQ를 반복하지 않는다. 필요한 답은 본문에 한 번씩 배치하고 출처는 해당 설명 가까이에 직접 연결한다. 긴 면책문 여러 개가 잘못된 첫 문장을 보완해 주지는 않는다.

## 대조한 직접 문서

- [AHA 안정 시 심박수와 측정](https://www.heart.org/en/healthy-living/exercise-and-physical-activity/fitness-basics/target-heart-rates): 일반 범위, 영향을 주는 요인, 손목 측정 방법.
- [NHS 두근거림](https://www.nhs.uk/symptoms/heart-palpitations/)과 [부정맥](https://www.nhs.uk/conditions/arrhythmia/): 현재 지속되는 증상과 응급 동반 증상, 반복되는 증상의 상담, 증상이 멎은 뒤의 신속한 평가를 구분.
- [FDA 카페인 안내](https://www.fda.gov/consumers/consumer-updates/spilling-beans-how-much-caffeine-too-much): 함량·민감도 차이, 숨은 섭취원, 감량 시 주의. 금단 기간을 두근거림 진단의 기준으로 제시하는 자료가 아니다.
- [NICE NG196 1.1.1~1.1.3](https://www.nice.org.uk/guidance/NG196/chapter/recommendations): 의심 심방세동의 심전도 확인과 증상 간격에 따른 추가 기록. 직접 열기는 403이 있었으나 공식 도메인 검색에서 해당 권고의 전체 문맥을 확인했다. 다른 부정맥 모두의 검사 순서로 확대하지 않는다.
- [삼성 한국어 ECG 사용설명서](https://images.samsung.com/samsung-health/ifu/IFU_ECG_KR.pdf)와 [국내 기능 안내](https://www.samsung.com/sec/apps/samsung-health-monitor/): 알림과 직접 측정, 한계와 사용 제한, 기록 보고서. 확인한 PDF에는 ECG App v1.3, 2026-03, v5.1이 표기돼 있다. 웹 안내의 이전 버전 결과 구간과 숫자를 섞지 않았다.
- [질병관리청 심근경색](https://health.kdca.go.kr/healthinfo/biz/health/ccvdInfo/cvcdInfo/miInfoMain.do), [NHLBI 증상](https://www.nhlbi.nih.gov/health/coronary-heart-disease/symptoms)과 [원인·예방](https://www.nhlbi.nih.gov/health/coronary-heart-disease/causes): 전형적 증상 설명과 즉시 도움을 요청하라는 행동 지침을 함께 읽었다. 질병관리청에도 기다리거나 약국 등을 거치며 시간을 쓰지 말라는 안내가 있다.
- [NHS 예방](https://www.nhs.uk/conditions/coronary-heart-disease/prevention/)과 [AHA 신체활동](https://www.heart.org/en/healthy-living/exercise-and-physical-activity/fitness-basics/aha-recs-for-physical-activity-in-adults): 생활관리와 처방약 유지, 일반 성인 활동 권고와 개인별 조정을 구분.
- [NHS 뇌졸중 증상](https://www.nhs.uk/conditions/stroke/symptoms/): 갑작스러운 신경 증상의 응급 대응. 국내 독자의 연락은 119로 안내한다.

공개 자료 대조와 편집 교정은 실제 의료 감수가 아니다. 새 감수 기록은 입력하지 않았다. 원래 발행일을 유지하고 네 교정본의 실제 수정일만 2026-10-23으로 기록했다. 관상동맥질환 글의 원래 발행 시각도 유지했다. 통합 보관본의 날짜는 바꾸지 않았다.

## 검증과 인계

전체 테스트 44개가 통과했다. 추가 여덟 검사는 날짜·감수 기록, 통합·태그·인코딩된 영구 이동, 직접 출처 연결, 맥박 범위와 카페인의 해석, 진료 지연 방지, 워치 기록의 역할, 흉통의 시간 조건 제거와 영문 별칭 목적지의 ASCII 인코딩을 회귀 검사한다. 문자열 검사가 임상적 정확성을 승인하지는 않는다.

747페이지 정적 빌드가 통과했다. 수정 전 공개 360편의 소스·본문·구조화 데이터를 저장했고, 이번 네 교정본과 한 통합 보관본을 제외한 기존 355편이 일치했다. 전체 공개 원고는 359편, 건강 글은 89편이다. 새 리다이렉트 세 개와 아래 영문 별칭의 목적지 인코딩 수정 외 기존 설정과 규칙은 모두 동일하다. 보관본의 HTML·raw·OG 출력은 생성되지 않고 정적 목록·검색·XML·LLM 안내에도 남지 않는다.

첫 운영 HTTP 검사에서 기존 `resting-pulse-95-thirties-cause`의 Location에 인코딩되지 않은 한글이 들어 있음을 확인했다. 이 값을 헤더 문자열로 받아 URL로 구성하는 클라이언트에서는 글자가 깨져 최종 404가 됐다. 같은 시점의 브라우저 이동은 정상임도 확인했으므로 모든 방문자가 404였다고 표현하지 않는다. 목적지를 퍼센트 인코딩해 클라이언트별 해석 차이를 제거하고, 기존 영문 주소까지 포함해 운영 이동을 재검사한다. 원고 본문과 날짜는 이 후속 수정에서 바꾸지 않았다.

사이트맵은 99개 중 건강 89개이며 건강 수정일 누락은 없다. 네 교정본의 실제 수정일을 확인했고 RSS 50개는 모두 건강 글이다. 건강 소스 93개 중 통합 보관본은 4개다. 기관 홈페이지 참조의 기계적 검토 대상은 44편에서 41편으로 줄었지만 이는 나머지 글의 오류 확정이나 출처 검증 완료를 뜻하지 않는다. 공개 건강 글 89편 모두 현재 내용의 실제 의료 감수 기록은 없다.

운영 주소·본문·XML·화면과 GSC 확인 증거는 소유자의 `output/healthpick-2026-10-23-cardiac` 폴더에 기록한다. 개인 계정 화면과 GSC 원본은 공개 저장소에 넣지 않는다. 색인 요청 접수와 실제 색인·노출·클릭은 구분해서 보고하며 이미 요청한 URL을 반복 제출하지 않는다.

다음 교정에서도 증상의 전형적인 기간을 최소 대기 조건으로 바꾼 표·요약·FAQ부터 점검한다. 약물 복용 뒤 검은 변, 지속되는 명치 통증, 호흡기 증상 등에서도 같은 오류가 있는지 직접 근거와 대조할 필요가 있다. 자동 대량 발행이나 통합 보관본의 재공개는 재개하지 않는다. 미추적 `scripts/quality-audit.mjs`는 수정하거나 커밋하지 않는다.
