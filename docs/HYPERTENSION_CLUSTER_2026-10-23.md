# Healthpick 고혈압 글 교정과 중복 통합

## 확인된 오류

생활습관 안내 글은 약물치료를 '보조'로 표현하고 수축기 130 이상 전체를 전단계로 분류했다. 140/95 글은 가정혈압 130/85를 135/85보다 낮다고 해석해 이완기 경계값을 놓쳤다. 145/90 운동 글은 사실상 같은 질문을 반복하면서 누구나 진료보다 기록을 먼저 모아야 하는 것처럼 안내했다. 이는 문장 다듬기만으로 해결할 문제가 아니라 치료 지연으로 읽힐 수 있는 내용 오류다.

## 변경 범위

| 대상 | 처리 |
| --- | --- |
| `/health/고혈압-예방-약-없이-먼저-손볼-7가지/` | 제목을 '혈압 관리를 돕는 생활습관 7가지'로 바꾸고 재작성. 약을 대신한다는 인상, 단정적인 효과 합산, 수면 시간보다 시각이 중요하다는 주장을 제거 |
| `/health/혈압-140-95-약-운동/` | 140/95와 145/90의 치료 결정 질문을 통합. 진료실·가정혈압의 차이와 '또는' 조건, 위험도 평가, 기록 방법과 응급 신호를 설명 |
| `/health/혈압-145-90-운동만으로-떨어질까/` | 원고는 삭제하지 않고 `draft: true`로 통합 보관. 공개 페이지·원문·OG 이미지는 대응되는 통합 주소로 영구 리다이렉트 |

수정한 두 글은 원래 발행일과 주소를 유지하고 `updatedDate`만 2026-10-23으로 기록했다. 생활습관 글의 기존 대표 글 설정도 유지했다. 중복 frontmatter·본문 FAQ를 제거하고 실제 의료 감수 기록은 만들지 않았다. 보관본은 새로 생성한 초안이 아니며, 다시 공개하거나 자동 발행하면 안 된다.

공개 건강 글은 92편에서 91편으로 줄어든다. 새 글을 추가하지 않은 통합 작업이다. 태그는 통합 글에 합쳐 기존 태그 목록의 연결을 유지한다. 이번 교정에 필요한 내부 링크는 생활습관, 치료 결정, 이미 교정한 복약 후 점검 글 사이에 둔다.

## 근거와 적용 조건

- [대한고혈압학회 2022 개정 지침](https://clinicalhypertension.org/DOIx.php?id=10.1186/s40885-023-00234-9)의 혈압 분류와 위험도별 초기 치료 원칙을 확인했다.
- [2026 개정 지침 주요 내용](https://clinicalhypertension.org/DOIx.php?id=10.5646/ch.2026.32.e31)을 대조했다. 전단계 중 고위험 또는 심혈관질환 동반 대상의 약물 고려는 Class IIb, 근거 수준 B인 조건부 권고다. 이를 모든 130대 혈압에 약이 필요하다는 말로 확대하지 않는다.
- [가정혈압포럼 입장문](https://clinicalhypertension.org/DOIx.php?id=10.1186/s40885-022-00218-1)의 평균 혈압 기준과 반복 측정을 사용했다. 130/85는 이완기 기준에 해당하므로 자동으로 백의고혈압이나 정상으로 설명하면 안 된다.
- 2026 국내 지침의 매우 높은 혈압과 급성 장기 손상 구분을 반영했다. 가정에서 응급 여부를 확진하도록 하지 않고, 응급 증상이 있으면 숫자와 무관하게 도움을 요청하도록 했다. 미국 안내의 180/120을 국내 기준으로 무비판적으로 복사하지 않는다.
- 나트륨은 [WHO](https://www.who.int/news-room/fact-sheets/detail/sodium-reduction), 식사 구성은 [NHLBI DASH](https://www.nhlbi.nih.gov/health/dash-eating-plan)를 사용했다. 각 안내의 서로 다른 나트륨 목표를 하나의 동일한 권고처럼 섞지 않았다. 다른 생활습관과 응급 증상은 글 안의 해당 기관 문서로 연결했다.

## 통합과 색인

`vercel.json`의 기존 형식인 `permanent: true`를 사용하며 이는 Vercel에서 308 영구 리다이렉트다. 통합 전 본문·raw Markdown·OG 이미지마다 대응되는 목적지를 지정했다. 관계없는 홈으로 보내지 않는다. [Google의 URL 이전 안내](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes)에 맞춰 통합한 내용으로 연결하고 기존 주소를 보존하는 조치다.

통합 보관본은 사이트맵·검색·목록·RSS·LLM 안내와 정적 본문·원문·이미지 생성에서 빠져야 한다. 리다이렉트는 유지하며 단기간에 제거하지 않는다. 글 수 감소, 리다이렉트 적용이나 사이트맵 갱신을 검색 유입 회복이라고 보고하지 않는다. 색인 요청 접수와 실제 색인은 다르다. 이번 작업을 이유로 이미 요청한 URL을 반복 제출하지 않는다.

## 검증과 인계

테스트 24개가 통과했다. 추가 5개는 발행일 유지, 감수 기록 조작 방지, 출처의 본문 연결, 이완기 경계값 설명, 통합 보관과 세 리다이렉트 설정을 확인한다. 이는 원고의 의학적 적절성을 자동 승인하는 검사가 아니다.

745페이지 정적 빌드가 통과했다. 수정 대상이 아닌 359편의 원고 해시, 출력 본문과 구조화 데이터가 이전 배포와 일치했다. 통합 전 페이지·원문·이미지는 생성되지 않고 모든 HTML·목록에서 기존 주소가 빠졌다. 사이트맵은 101개 중 건강 URL 91개이며, 두 수정 글의 실제 수정일이 반영되고 건강 글 수정일 누락은 없다. RSS 50개는 모두 건강 글이다.

운영 주소와 화면 검증 결과는 이어서 확인하며 소유자의 `output/healthpick-2026-10-23-hypertension` 폴더에 별도로 남긴다. 기계적 출처 점검은 공개 91편 중 기관 홈페이지 참조 검토 대상 49편으로 집계됐다. 감수 기록은 공개 91편 모두 아직 등록돼 있지 않다. 출처 링크를 달았다는 이유로 감수 완료로 표시하지 않는다.

Claude는 다음 사항을 지켜야 한다.

1. 새 숫자만 바꾼 '운동만으로 약을 피할 수 있나' 글을 만들지 않는다. 독자의 질문과 다음 행동이 같으면 기존 글을 개선한다.
2. 요약·FAQ·본문을 함께 교정한다. '정상', '미만', '이상' 같은 경계값은 수축기와 이완기를 각각 확인한다.
3. 생활요법과 약물을 성공·실패로 나누거나 약물을 단순 보조로 낮추지 않는다. 관찰 기간을 진료를 미뤄도 되는 기간처럼 안내하지 않는다.
4. 고혈압 전단계·진단 기준·개인별 치료 목표를 구분하고, 지침의 연도와 대상·권고 강도를 보존한다.
5. 개선 여부는 GSC 보고서의 갱신일, 실제 색인 URL과 클릭으로 확인한다. 740개 제외를 모두 현재 건강 글의 오류라고 해석하거나, 요청 성공을 회복 증거로 사용하지 않는다.

미추적 `scripts/quality-audit.mjs`와 다른 분야의 기존 원고는 변경하지 않았다. 자동 대량 발행도 재개하지 않는다.
